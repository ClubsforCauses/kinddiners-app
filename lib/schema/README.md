# Schema types

Starter TypeScript types for the platform-v2 future-state database schema.

- **Source of truth:** `platform-v2/docs/FUTURE_STATE_SCHEMA.md`
- **Migration mapping:** `platform-v2/docs/LEGACY_TO_NEW_MIGRATION_MAP.md`

Use these types for API request/response shapes, form validation (e.g. Zod), and Supabase client typings. They do not implement ORM or queries.
