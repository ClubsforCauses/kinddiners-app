# Database layer (Drizzle ORM)

- **Schema:** `lib/db/schema/` — enums, tables, relations. Source: `docs/FUTURE_STATE_SCHEMA.md`.
- **Client:** `lib/db/client.ts` — `db` instance (use in API routes and server code).
- **Migrations:** `lib/db/migrations/` — SQL migrations generated by `drizzle-kit generate`.

## Setup

1. Set `DATABASE_URL` (e.g. in `.env.local`):  
   `postgresql://user:pass@host:5432/kinddiners`
2. Run migrations:  
   `npm run db:migrate` (or apply `lib/db/migrations/*.sql` with your Postgres client).
3. Optional: push schema without migration files:  
   `npm run db:push`

## Scripts

- `npm run db:generate` — generate new migration from schema changes.
- `npm run db:migrate` — run pending migrations.
- `npm run db:push` — push schema to DB (dev).
- `npm run db:studio` — open Drizzle Studio.

## Roles

Profiles use `role`: `member` | `restaurant_admin` | `admin`. Enforced in app logic and (when added) auth middleware.
